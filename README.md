# CIB-Koffer Web

Statische Website „Labor to go“ der Hochschule Esslingen.

## Cloudflare Pages

- Projektname: `cib-koffer-web`
- Produktionsbranch: `main`
- Framework: None
- Build command: `npm run build`
- Build output directory: `dist`
- Root directory: Repository root
- Zieladresse: https://cib-koffer-web.pages.dev

Keine Abhängigkeiten oder Serverfunktionen. Das Anfrageformular öffnet das lokale E-Mail-Programm; eine E-Mail wird erst dort versendet. Schriften werden von Google Fonts geladen. Die Kofferabbildung ist eine SVG-Illustration.
